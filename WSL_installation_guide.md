# Полное руководство по установке Kali Linux в WSL2 с графическим интерфейсом (XRDP) и без паролей

Решение проблем с вылетами, сбросом паролей, конфликтами с WSLg и запуском в один клик.

---

### ЭТАП 1. Чистая установка и гарантированная настройка пароля
*Выполняется в стандартном **PowerShell Windows** (запущенном от имени администратора):*

1. **Полное удаление старой системы** (чтобы стереть прошлые хвосты и конфликты):
   ```powershell
   wsl --shutdown; wsl --unregister kali-linux
   ```
2. **Чистая установка новой Kali Linux**:
   ```powershell
   wsl --install -d kali-linux
   ```
3. Дождитесь завершения загрузки. Когда откроется окно Kali, введите имя пользователя `roma` маленькими буквами.
4. **ЕСЛИ ВЫ ОШИБЛИСЬ ПРИ ВВОДЕ ПАРОЛЯ** (или получили ошибку *Authentication token...*):
   * Просто закройте окно Kali Linux крестиком.
   * Вернитесь в PowerShell Windows и зайдите в Kali под суперпользователем `root`:
     ```powershell
     wsl -d kali-linux -u root
     ```
   * В открывшейся консоли (строка станет красной) принудительно задайте пароль:
     ```bash
     passwd roma
     ```
   * Введите ваш новый пароль дважды вслепую (символы на экране не появятся).
   * Закройте консоль командой `exit`.

### ЭТАП 2. Настройка Windows против вылетов и конфликтов графики
*Выполняется в **PowerShell Windows** (от имени администратора):*

1. Откройте глобальный файл конфигурации WSL:
   ```powershell
   notepad "$env:USERPROFILE\.wslconfig"
   ```
2. Полностью сотрите всё, что там есть, и вставьте следующий текст. Эти параметры отключают мешающий движок WSLg и жестко **запрещают Windows усыплять как саму систему, так и инстанс Kali** при потере фокуса окон:
   ```text
   [wsl2]
   guiApplications=false
   vmIdleTimeout=-1

   [general]
   instanceIdleTimeout=-1
   ```
3. Сохраните файл (`Ctrl + S`) и закройте Блокнот.

---

### ЭТАП 3. Настройка графики и беспарольного режима внутри Linux
*Зайдите в Kali Linux (через Пуск или команду `wsl -d kali-linux`). По очереди вставляйте эти команды в терминал:*

1. **Обновление системы и установка рабочего стола XFCE с RDP-сервером:**
   ```bash
   sudo apt update && sudo apt upgrade -y
   sudo apt install kali-desktop-xfce xrdp -y
   ```
   *(Система один раз попросит ваш пароль).*

2. **Отключение ввода пароля для команды `sudo` (чтобы Kali больше никогда его не просила):**
   ```bash
   sudo visudo
   ```
   Спуститесь стрелочками на клавиатуре в самый низ открывшегося файла и вставьте строку:
   ```text
   roma ALL=(ALL) NOPASSWD:ALL
   ```
   Нажмите `Ctrl + O` -> `Enter` -> `Ctrl + X` для сохранения и выхода.

3. **Конфигурация XRDP-сервера (вставка команд по одной):**
   ```bash
   # Переносим RDP на порт 3390, чтобы избежать системных конфликтов с Windows
   sudo sed -i 's/port=3389/port=3390/g' /etc/xrdp/xrdp.ini

   # Отключаем принудительные проверки сетевых групп пользователей Windows
   sudo sed -i 's/TerminalServerUsers=tsusers/#TerminalServerUsers=tsusers/g' /etc/xrdp/sesman.ini
   sudo sed -i 's/TerminalServerAdmins=tsadmins/#TerminalServerAdmins=tsadmins/g' /etc/xrdp/sesman.ini

   # Настраиваем бесконечную сессию по таймауту
   sudo sed -i 's/DisconnectTimeLimit=0/DisconnectTimeLimit=0/g' /etc/xrdp/sesman.ini
   sudo sed -i 's/IdleTimeLimit=0/IdleTimeLimit=0/g' /etc/xrdp/sesman.ini
   sudo sed -i 's/tcp_keepalive=false/tcp_keepalive=true/g' /etc/xrdp/xrdp.ini

   # Привязываем запуск интерфейса XFCE
   echo "exec dbus-launch --exit-with-session startxfce4" > ~/.xsession
   ```

4. **Полная пересборка скрипта запуска (защита от крашей при сворачивании):**
   ```bash
   sudo nano /etc/xrdp/startwm.sh
   ```
   * Полностью очистите файл (зажмите `Ctrl + K` для быстрого удаления всех строк).
   * Вставьте вместо старого текста эти 6 чистых строк:
   ```bash
   #!/bin/sh
   if [ -r /etc/profile ]; then . /etc/profile; fi
   unset DBUS_SESSION_BUS_ADDRESS
   unset XDG_RUNTIME_DIR
   export DESKTOP_SESSION=xfce
   exec startxfce4
   ```
   * Нажмите `Ctrl + O` -> `Enter` -> `Ctrl + X` для сохранения и выхода. Напишите `exit`, чтобы закрыть Linux.

### ЭТАП 4. Создание идеального ярлыка в Windows
1. На рабочем столе Windows: **Правая кнопка мыши** -> **Создать** -> **Ярлык**.
2. В поле «Укажите расположение объекта» вставьте команду автоматического запуска:
   ```cmd
   cmd.exe /c "wsl -d kali-linux -u root service xrdp start && start mstsc.exe /v:localhost:3390"
   ```
3. Нажмите «Далее», назовите ярлык (*Kali Linux GUI*) и нажмите «Готово».
4. Кликните по созданному ярлыку правой кнопкой мыши -> **Свойства**. Вкладка *«Ярлык»* -> пункт **«Окно»** -> выберите **«Свернутое в значок»**. Нажмите ОК. (Это скроет черную консоль cmd при старте).

### ЭТАП 5. Сохранение пароля в Windows (Делается 1 раз)
1. Дважды кликните по вашему новому ярлыку на рабочем столе. Откроется синее окно Windows.
2. В левом нижнем углу нажмите кнопку **«Показать параметры»**.
3. В поле «Пользователь» впишите строго маленькими латинскими буквами: **`roma`**.
4. Поставьте галочку **«Разрешить мне сохранять учетные данные»**.
5. Нажмите кнопку **«Подключиться»**.
6. Windows откроет окно авторизации и попросит ввести пароль от вашей Kali Linux. Введите его, обязательно отметьте галочку **«Запомнить меня»** и заходите.

### 📂 Как пользоваться общей папкой
Вы можете в любой момент открыть файлы вашей Kali Linux прямо в обычном Проводнике Windows, чтобы перетаскивать документы мышкой. 
Для этого в адресную строку Проводника введите: 
```text
\\wsl\$\kali-linux\home\roma
```

### ЭТАП 6. Установка инструментов (Kali Top 10) и прокачка системы
*Выполняется в терминале внутри Kali Linux (внутри графической оболочки или через консоль):*

1. **Установка главного арсенала утилит:**
   По умолчанию Kali в WSL поставляется пустой. Установите топ-10 самых популярных инструментов (Nmap, Wireshark, Metasploit, John critical-tools и др.) одной командой:
   ```bash
   sudo apt install kali-tools-top10 -y
   ```

2. **Включение современной интерактивной оболочки Zsh (По желанию):**
   Чтобы сделать терминал красивым, с автодополнениями и подсветкой, введите:
   ```bash
   kali-tweaks
   ```
   В открывшемся псевдографическом меню выберите **Shell**, переключите его на **Zsh**, после чего перезапустите терминал.

### ЭТАП 7. Отключение окон авторизации Polkit (Запрос пароля при выключении)
Если при попытке закрыть, перезагрузить или выключить графическую сессию XFCE у вас всплывает окно *"Authentication is required to power off the system"*, это лечится добавлением JavaScript-правила для службы авторизации.

1. **Создайте файл конфигурации правил Polkit:**
   ```bash
   sudo nano /etc/polkit-1/rules.d/45-allow-power-actions.rules
   ```

2. **Вставьте в файл следующий код целиком:**
   ```javascript
   polkit.addRule(function(action, subject) {
       if ((action.id == "org.freedesktop.login1.power-off" ||
            action.id == "org.freedesktop.login1.power-off-multiple-sessions" ||
            action.id == "org.freedesktop.login1.reboot" ||
            action.id == "org.freedesktop.login1.reboot-multiple-sessions") &&
           subject.user == "roma") {
           return polkit.Result.YES;
       }
   });
   ```

3. **Сохраните изменения:** Нажмите `Ctrl + O` -> `Enter` -> `Ctrl + X`.

4. **Перезапустите службу авторизации для применения настроек:**
   ```bash
   sudo systemctl restart polkit
   ```

### ЭТАП 8. Интерактивная настройка масштаба интерфейса (scale.sh)
Если после первого запуска элементы графического стола XFCE (шрифты, верхняя панель или значки) кажутся слишком мелкими через RDP, используйте готовый скрипт `scale.sh`. Он позволяет плавно подогнать размеры под ваш монитор на лету с живым превью.

#### Как создать и запустить скрипт:
1. Создайте пустой файл в терминале Kali Linux:
   ```bash
   nano scale.sh
   ```
2. Скопируйте код скрипта из этого репозитория, вставьте его в открывшееся окно, сохраните изменения (`Ctrl + O`, затем `Enter`) и выйдите (`Ctrl + X`).
3. Сделайте созданный файл исполняемым и запустите его:
   ```bash
   chmod +x scale.sh && ./scale.sh
   ```

#### ⌨️ Управление в процессе настройки:
* **`w`** + `Enter` — увеличить элементы (DPI / высоту панели / размер иконок).
* **`s`** + `Enter` — уменьшить элементы.
* **`Enter`** (пустая строка) — сохранить текущий шаг и автоматически перейти к следующему пункту.


### ЭТАП 9. Создание точки восстановления (Бэкап системы)
Чтобы в случае неудачных экспериментов не проходить весь этот путь настройки заново, обязательно сделайте чистый слепок готовой системы.

1. Полностью закройте графическое окно Kali Linux.
2. Откройте **PowerShell Windows** от имени администратора и выполните:
   ```powershell
   wsl --shutdown
   wsl --export kali-linux C:\kali-backup.tar
   ```
3. Теперь на вашем диске `C:\` лежит готовый архив `kali-backup.tar`. 

*Если система когда-либо сломается, вы сможете вернуть её к этому идеальному состоянию двумя командами в PowerShell:*
```powershell
wsl --unregister kali-linux
wsl --import kali-linux \$env:USERPROFILE\KaliLinux C:\kali-backup.tar
```
